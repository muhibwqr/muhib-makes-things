gpt-2 in latex

november 2026

15 compiles,
one word each

Preface

GPT-2 small, all 124M parameters, running inside an ordinary pdflatex compile. No Python, Lua, or shell escape. The repo is 100% TeX.

Overview

About 20 seconds per token. Every time you hit compile, the PDF writes one more word. It picks exactly the same tokens as the original float GPT-2.

the frat house next to my waterloo rental kept me up all night, so i got gpt-2 running purely in latex.

how it works

Matmuls are TeX's \numexpr integer arithmetic. Each weight row is one expression TeX evaluates as it reads the file.

% one weight row in the file (bytes 128-255 are active chars = input registers)
\!S-105*^^80-38*^^81+32*^^82+128*^^83-46*^^84-76*^^85 ... \relax

% muhib-gpt2.sty
\def\!S{\advance\gpt@ai\@ne\count\gpt@ai=\numexpr0}
\def\!U{\advance\gpt@ai\@ne\count\gpt@ai=\numexpr\count\gpt@ai}

The KV cache uses the same trick LaTeX uses to remember page numbers between runs, so each compile picks up where the last one stopped.

% muhib-gpt2.sty: K and V for each layer/position/head become macros,
% then get written to \jobname.gpt (like .aux) at the end of the compile
\def\gpt@wr#1{\immediate\write\gpt@sf{\noexpand\gpt@kv{#1}%
  {\unexpanded\expandafter\expandafter\expandafter{\csname#1\endcsname}}}}

% what lands in muhibai.gpt
\gpt@kv {gpt@K0.0.0}{0+-242*\!Qaa +488*\!Qab +225*\!Qac +-38*\!Qad ...}

The tokenizer is GPT-2's real byte-level BPE, written as TeX macros. So are layer norm, softmax, GELU, and the 50,257-way output head.

% muhib-gpt2.sty: bytes -> GPT-2 byte tokens, then apply merges by rank
\def\gpt@bpe{\gpt@loop{\gpt@pl}{\gpt@byteid{\gpt@PB\gpt@i}\gpt@PB\gpt@i=\gpt@t}\gpt@merge ...}
\def\gpt@merge{\gpt@br=2147483647 ...
  \ifnum\gpt@br<2147483647 \gpt@bi=0 \gpt@bo=0 \gpt@mergepass\gpt@pl=\gpt@bo\expandafter\gpt@merge\fi}

converting the weights thru latex

The most annoying part. pdflatex reads GPT-2's raw 548 MB checkpoint byte by byte with \pdffiledump, decodes every IEEE-754 float with integer math, and writes all 780 weight files. The first version took 22 minutes; now it's 92 seconds across 12 pdflatex processes.
